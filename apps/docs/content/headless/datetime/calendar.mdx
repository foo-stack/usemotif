# Calendar

<Lede>
  Calendar is a focusable month grid. The arrow keys move day by day, PageUp and PageDown jump a
  month, and the labels are locale-aware - all without styling.
</Lede>

<ComponentDemoStrip demo="calendar" />

## What it is

A single component - not compound - that renders a `role="grid"` month view. It manages two
pieces of state: the selected date and the focused date. The selected date is what the user
chose; the focused date is where keyboard navigation currently sits, and moving it past the
month's edge scrolls the grid.

Weekday and month labels come from `Intl.DateTimeFormat`, so they follow the `locale`. The
`renderDay` prop replaces the content of each cell, leaving the grid and the keyboard model
intact.

## Range selection

`mode="range"` picks a start and an end date. The first pick starts the range, the second
finishes it, and a second pick earlier than the first swaps the two. Picking again after that
starts a new range.

<CodeBlock lang="ts" code={`interface DateRange {
  readonly start: Date;
  readonly end: Date | null; // null until the second pick
}`} />

<CodeBlock lang="tsx" code={`const [range, setRange] = useState<DateRange>();

<Calendar mode="range" value={range} onValueChange={setRange} />`} />

`onValueChange` fires on both picks, so `end` is `null` after the first. Every day in the range
is `aria-selected`, and `renderDay` receives `isRangeStart`, `isRangeEnd` and `isInRange` to
paint the ends and the days between. The native Calendar takes the same `mode`, with the same
rule and flags.

## Keyboard

| Key | Action |
| --- | --- |
| Arrow Left / Right | Previous / next day |
| Arrow Up / Down | Previous / next week |
| PageUp / PageDown | Previous / next month |
| Home / End | Start / end of the current week |
| Enter / Space | Select the focused day (in range mode, the start or the end) |

## Accessibility

Calendar is a `role="grid"` with `row`, `columnheader`, and `gridcell` descendants - the WAI-ARIA
grid pattern, so a screen reader announces it as a date grid and reads each cell's full date.
Roving `tabindex` keeps exactly one cell in the Tab order: a keyboard user tabs into the grid
once, navigates with the arrow keys, and tabs straight out. Selected cells carry `aria-selected`;
disabled cells carry `aria-disabled` and are skipped on selection.

## Examples

A calendar with a minimum date:

<CodeBlock lang="tsx" code={`<Calendar
  value={date}
  onValueChange={setDate}
  weekStartsOn={1}
  isDisabled={(d) => d < new Date()}
  renderDay={({ date, isSelected, isToday }) => (
    <Box
      p="$1"
      borderRadius="$radii.sm"
      bg={isSelected ? '$colors.action.primary.bg' : undefined}
      fontWeight={isToday ? '$bold' : undefined}

      {date.getDate()}
    </Box>
  )}
/>`} />
