# Menu

<Lede>
  Menu is the headless dropdown - a trigger button, a panel of actions, and the full keyboard
  contract: arrow keys, Home and End, Enter to activate, Escape to close.
</Lede>

<ComponentDemoStrip demo="menu" />

<ArticleMeta />

## What it is

A compound component for a list of actions hung off a trigger. `Menu.Content` renders into a
[Portal](/components/utilities/portal), positioned against the trigger. Each `Menu.Item` is a
`role="menuitem"` row; `Menu.Separator` divides groups. The panel manages focus - opening it
focuses the first enabled item, and the arrow keys move between items from there.

### Menu.Separator

A `role="separator"` divider between item groups. Takes an optional `style`.

### Menu.Sub, Menu.SubTrigger, Menu.SubContent

A submenu. `Menu.Sub` groups a `Menu.SubTrigger`, which is an item of the surrounding menu, with
the `Menu.SubContent` it opens beside it. Submenus nest, and one submenu per menu level is open
at a time.

<CodeBlock lang="tsx" code={`<Menu.Sub>
  <Menu.SubTrigger>Share</Menu.SubTrigger>
  <Menu.SubContent>
    <Menu.Item onSelect={emailLink}>Email link</Menu.Item>
    <Menu.Item onSelect={copyLink}>Copy link</Menu.Item>
  </Menu.SubContent>
</Menu.Sub>`} />

- **`Menu.SubTrigger`** takes `disabled`, `style`, `asChild` and `children`, like `Menu.Item`.
  Hovering or clicking it opens the submenu without moving focus.
- **`Menu.SubContent`** takes `offset` (px between trigger and panel, default `0`), `style` and
  `children`. Choosing an item inside closes the whole menu and returns focus to the trigger,
  and clicks inside an open submenu never count as outside the menu.

`ContextMenu.Sub`, `ContextMenu.SubTrigger` and `ContextMenu.SubContent` are the same parts. On
React Native a submenu expands inline within the menu sheet.

## Keyboard

| Key | Action |
| --- | --- |
| Arrow Down / Up on the trigger | Open the menu |
| Arrow Down / Up in the panel | Move focus between items, wrapping |
| Home / End | Focus the first / last enabled item |
| Enter / Space | Activate the focused item, or open the focused submenu |
| Arrow Right on a submenu trigger | Open the submenu and focus its first item |
| Arrow Left in a submenu | Close the submenu, returning focus to its trigger |
| Escape | Close the innermost open menu, returning focus to its trigger |

## Accessibility

Menu implements the WAI-ARIA menu-button pattern. The trigger carries `aria-haspopup="menu"` and
`aria-expanded`; the panel is `role="menu"`; each item is `role="menuitem"`. Disabled items get
`aria-disabled` and are skipped by the arrow keys, so a keyboard user never lands on a dead row.
Opening the menu moves focus to the first enabled item; closing it - by selection or Escape -
returns focus to the trigger.
