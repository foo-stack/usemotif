# PinInput

<Lede>
  PinInput takes a verification code one character per box. Typing moves to the next box,
  pasting or autofilling a code fills them all, and Backspace steps back.
</Lede>

<ArticleMeta />

## What it is

A `role="group"` of `length` single-character inputs sharing one string value. Characters the
`type` does not accept are dropped as they are typed or pasted. When every box is filled,
`onComplete` fires once with the code.

On the web the first box carries `autocomplete="one-time-code"`, so a code the browser or the
operating system offers lands whole and spreads across the boxes; numeric codes also ask for
the numeric keyboard. On React Native the boxes are `TextInput`s with the number pad, and the
first carries `textContentType="oneTimeCode"` and `autoComplete="sms-otp"`.

## Keyboard

| Key | Action |
| --- | --- |
| A character | Fill this box and move to the next |
| Backspace | Clear this box, or the one before an empty box, and move back |
| Arrow Left / Right | Move between boxes |
| Paste | Fill from this box onward |

## Accessibility

Each box is labelled "Character N of M", and the group takes your `aria-label`, so a screen
reader announces both the code's purpose and the position. Do not hide the label visually
without giving the group a name some other way.
