# Listbox

<Lede>
  Listbox is a list of options that stays on the page, for a settings panel or a sidebar picker.
  It moves by arrow keys and type-ahead, and selects one option or several.
</Lede>

<ArticleMeta />

## What it is

A focusable `role="listbox"`. Focus stays on the list while `aria-activedescendant` points at the
highlighted option, the same model as the [Combobox](/headless/selection/combobox) popup, whose
option rows it shares. Options are the Combobox's `{ value, label, disabled? }` objects.

## Keyboard

| Key | Action |
| --- | --- |
| Arrow Down / Up | Highlight the next / previous enabled option |
| Home / End | Highlight the first / last enabled option |
| A letter or word | Jump to the next option whose label starts with it; repeating one letter cycles |
| Enter / Space | Select the highlighted option, or toggle it in multiple mode |

Typed characters build one search for half a second, so typing "apr" quickly lands on "Apricot"
rather than stopping at "Apple".

## Accessibility

Name the list with `aria-label` or `aria-labelledby`. Focusing it highlights the selected option,
or the first enabled one. On React Native the options are Pressables with
`accessibilityState.selected` in a list.
