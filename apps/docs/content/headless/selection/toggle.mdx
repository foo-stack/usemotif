# Toggle

<Lede>
  Toggle is a button that stays pressed until it is pressed again: bold in a text editor, mute on
  a call. It is a real `<button>` with `aria-pressed`.
</Lede>

<ArticleMeta />

## What it is

A `<button type="button">` that flips its pressed state on click, Enter, or Space. It carries
`aria-pressed` for assistive technology and `data-state="on"` or `"off"` for styling. Any other
button prop passes through. For a row of toggles that share one value or several, use
[ToggleGroup](/headless/selection/toggle-group).

## Accessibility

A toggle needs a name that does not change with its state - "Bold", not "Make bold" - because
`aria-pressed` already announces whether it is on. Give an icon-only toggle an `aria-label`. On
React Native it is a Pressable announced as a toggle button, with `accessibilityState.checked`.

## Example

<CodeBlock lang="tsx" code={`const [bold, setBold] = useState(false);

<Toggle pressed={bold} onPressedChange={setBold} aria-label="Bold">
  <BoldIcon />
</Toggle>`} />
