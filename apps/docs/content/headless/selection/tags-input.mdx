# TagsInput

<Lede>
  TagsInput collects free-text entries as tags: topics, recipients, labels. It is a text input that
  turns what you type into a list, with optional suggestions.
</Lede>

<ArticleMeta />

## What it is

Enter or a delimiter (a comma by default) adds the typed entry; a paste adds every entry in it;
Backspace in an empty input removes the last tag. Each tag is drawn by `renderTag`, which gets a
`remove` callback. With `suggestions`, the input becomes the headless
[Combobox](/headless/selection/combobox) input, so the suggestion list has the combobox's keyboard
and ARIA, and picking a suggestion adds it instead of filling the input. For a fixed set of
options with no free text, use [MultiSelect](/headless/selection/multi-select).

## Keyboard

| Key | Action |
| --- | --- |
| Enter | Add the typed entry, or the highlighted suggestion |
| A delimiter | Add the typed entry |
| Backspace in an empty input | Remove the last tag |
| Arrow Down / Up | Move through the suggestions |
| Escape | Close the suggestions |

## Accessibility

Give each tag's remove control a name that says which tag it removes, as the default does. On
React Native the field is a `TextInput`: submitting or a typed delimiter adds the entry, and
suggestions show as a pressable list while typing.
