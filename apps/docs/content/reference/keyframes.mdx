## Description

Builds a named keyframe sequence that motion props consume directly. The returned `Keyframe` is a
branded type - motif's runtime recognises it on the `animation` prop and emits the matching
`@keyframes` rule into the page stylesheet alongside the using component's class.

A `Keyframe` is stable across renders. Define it at module scope and reference it from inside the
component; defining it inline allocates on every render.

## KeyframeDef

<CodeBlock lang="ts" code={`interface KeyframeDef {
  readonly [selector: string]: Record<string, string | number>;
}`} />

Selectors are the literal CSS keyframe selectors: `'0%'`, `'50%'`, `'100%'`, `'from'`, `'to'`,
or a comma list such as `'0%, 100%'`. Values are CSS properties in camelCase (`opacity`,
`transform`, `backgroundColor`) with literal values or token references. Style-prop shorthands
such as `bg` and `p` are not expanded here.

## Example

<CodeBlock lang="tsx" filename="Toast.tsx" code={`import { keyframes, Box } from 'usemotif';

const slideIn = keyframes({
  from: { transform: 'translateY(8px)', opacity: 0 },
  to: { transform: 'translateY(0)', opacity: 1 },
});

export function Toast({ children }: { children: React.ReactNode }) {
  return (
    <Box
      role="status"
      bg="$colors.surface.raised"
      color="$colors.text.default"
      p="$space.3"
      borderRadius="$radii.md"
      animation={{ name: slideIn, duration: '$durations.3', easing: '$easings.standard' }}
    >
      {children}
    </Box>
  );
}`} />

## Where keyframes resolve

The runtime emits the `@keyframes` rule once per unique definition and hashes the resulting name.
A hundred toasts sharing the same `slideIn` produce one keyframe rule, one class on each toast,
and no duplication.

## On React Native

Native has no `@keyframes` rule, so `Box` runs the stops itself on the JavaScript thread, honouring
`duration`, `delay`, `easing`, `iterationCount`, `direction`, `fillMode` and `playState`.

- **Interpolated:** numbers, colours, lengths that share a unit, and `transform` lists whose
  functions appear in the same order at each stop.
- **Switched halfway:** every other value, as CSS does for discrete properties.
- **Token references** resolve against the active theme. `Npx` lengths become plain numbers.
- **Not run on native:** a string `name`, which refers to a CSS rule native cannot read, and an
  `animation` on a `Box` that also sets `enterStyle`, `exitStyle` or a motion value, where those
  keep precedence.
