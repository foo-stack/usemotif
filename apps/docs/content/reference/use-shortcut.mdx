## Description

Exported from `@usemotif/headless`. The hook returns the shortcut's label for display: `⌘K` on Apple
platforms and `Ctrl+K` elsewhere, with modifiers in each platform's usual order. The first render
returns the non-Apple form and the label settles after mount, so server and client markup agree.

On React Native the shortcut never fires, since touch devices have no global hardware keyboard. The
label is still returned, in the Apple form on iOS, so shared code can show it.

`useCommandPaletteShortcut` is this hook with `allowInInputs` on, so the palette opens even from its
own search box.

## Example

<CodeBlock lang="tsx" code={`import { useShortcut } from '@usemotif/headless';
import { Button, Kbd } from 'usemotif';

function SaveButton({ onSave }: { onSave: () => void }) {
  const label = useShortcut('mod+s', onSave);
  return (
    <Button onPress={onSave}>
      Save <Kbd>{label}</Kbd>
    </Button>
  );
}`} />

Scoped to one element, here a list that takes `j` and `k` only while it has focus:

<CodeBlock lang="tsx" code={`const list = useRef<HTMLDivElement>(null);
