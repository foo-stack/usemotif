## Description

A thin factory. The returned object is exactly the input - `createTheme` does no transformation
at runtime. The type parameter `T extends TokenMap` preserves the literal shape of
`Theme.tokens`, which is what lets `$`-reference paths be derived from it. Those paths
autocomplete once you declare the theme; see
[Token autocomplete](/guides/token-autocomplete).

Pass the result to `ThemeProvider`'s `themes` array. The provider emits the CSS variables and
sets `data-theme` to one of the theme names.

`fonts`, `root`, and `reducedMotion` are optional web-only emission hints - `<ThemeProvider>`
picks them up to emit `@font-face` rules, document-root styles, and the reduced-motion policy.
They have no effect on native, where there is no stylesheet to emit into.

## Examples

<CodeBlock lang="ts" code={`import { createTheme } from 'usemotif';

export const lightTheme = createTheme({
  name: 'light',
  tokens: {
    colors: {
      ink: '#1C1917',
      paper: '#FBF7F2',
      blue: { 500: '#2563EB', 600: '#1D4ED8' },
      surface: { base: '$colors.paper' },
      text: { default: '$colors.ink' },
      action: { primary: { bg: '$colors.blue.600', fg: '$colors.paper' } },
    },
    space: { 1: 4, 2: 8, 4: 16 },
    radii: { sm: 4, md: 8, lg: 12 },
  },
});`} />

Both primitive and semantic tokens live in the same tree. Semantic tokens reference primitives by
`$colors.<path>`; the resolver walks the dotted path until it reaches a literal value.

## Extending a theme

`extendTheme(base, { name, tokens })` derives a theme from an existing one, such as the
`lightTheme` preset from `@usemotif/tokens`. The override tokens are deep-merged over the
base's, scale by scale and key by key, so you restate only what changes:

<CodeBlock lang="ts" code={`import { extendTheme } from 'usemotif';
import { lightTheme } from '@usemotif/tokens';

export const brandTheme = extendTheme(lightTheme, {
  name: 'brand',
  tokens: {
    colors: {
      violet: { 600: '#7C3AED' },
      action: { primary: { bg: '$colors.violet.600' } },
    },
  },
});`} />

- **Leaves replace.** A value in the overrides replaces the base's, and a whole branch can
  replace a leaf or the reverse.
- **Animation presets replace whole.** Each `animations` entry is one preset, so overriding
  `quick` replaces it rather than mixing its fields with the base's.
- **The rest is inherited.** `fonts`, `root`, and `reducedMotion` carry over unless the second
  argument gives them. `name` is required, because it becomes `data-theme`.
- **Types stay literal.** The result keeps the paths of both the base and the overrides, so
  `$colors.violet.600` and every preset path autocomplete. The presets themselves keep their
  literal shape for the same reason.

Neither argument is modified, so the base stays usable alongside the derived theme.
