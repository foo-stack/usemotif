## Description

Top-level theme provider. Renders a `<style>` element containing every theme's tokens, scoped to
`[data-theme="<name>"]`, and wraps its children in a `<div data-theme={active}>`.

A theme switch is a single attribute write - set `active` to a different name and the cascade
flips. No React re-renders, no unmount/remount.

Sub-tree theme boundary. Switches the active theme for descendants by setting `data-theme` on a
wrapping element. The CSS-variable cascade handles the visual change; React state is not involved.

When nested inside a parent `<Theme>` (or `<ThemeProvider>`), motif composes the names with `_`
and looks for a registered combination theme. Pre-generate the combinations you care about and
pass them all to `<ThemeProvider themes={...}>` - they activate automatically when the chain
matches.

## Browser chrome

On web the root provider also points the browser's own chrome at the active theme, from two
optional theme fields:

- **`colorScheme`** (`'light'` or `'dark'`) is set as `color-scheme` on `<html>`, and emitted in
  the theme's CSS block, so scrollbars, native form controls and the default canvas match.
- **`themeColor`**, a colour or a `$`-token, is resolved to a literal and written to
  `<meta name="theme-color">`, which colours the mobile browser bar. A meta you rendered is
  updated in place and restored on unmount; metas with a `media` attribute, your own light and
  dark pair, are left alone.

Both follow theme switches. The `@usemotif/tokens` presets set them: `colorScheme` to match, and
`themeColor` to `$colors.surface.base`. A theme without the fields changes nothing. It runs in an
effect, so server and first client render stay identical; React Native ignores both.

## Example

<CodeBlock lang="tsx" code={`import { ThemeProvider, Theme, Box } from 'usemotif';
import { lightTheme, darkTheme, lightRed, darkRed } from './theme';

<ThemeProvider themes={[lightTheme, darkTheme, lightRed, darkRed]} active="light">
  <Box bg="$colors.surface.base">{/* light */}</Box>

  <Theme name="dark">
    <Box bg="$colors.surface.base">{/* dark */}</Box>

    <Theme name="red">
      <Box bg="$colors.surface.base">{/* dark_red, if registered */}</Box>
    </Theme>
  </Theme>
</ThemeProvider>;`} />
