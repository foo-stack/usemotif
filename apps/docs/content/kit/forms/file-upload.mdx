# FileUpload

<Lede>
  FileUpload is a drop zone for files. Drag files onto it, or click it to open the file picker,
  and `onFiles` receives what was chosen.
</Lede>

<ArticleMeta />

## What it is

The headless [FileUpload](/headless/specialized/file-upload) behaviour with a themed zone. The
headless layer renders a hidden `<input type="file">` and tracks drag enter and leave, so the
dragging state holds while the pointer crosses child elements. Dropped files go through the same
`accept` and `multiple` filter as picked ones: files that do not match `accept` are dropped, and
without `multiple` only the first file is kept.

The kit zone is a centred box with a 2px dashed `border.strong` border on `surface.base`, showing
`label` in muted text. While files are dragged over it, the border turns `action.primary` and the
background `surface.muted`. Clicking it opens the picker.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { FileUpload } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { FileUpload } from '@usemotif/ui';

<FileUpload accept="image/*" multiple onFiles={(files) => upload(files)} />`} />

With a custom prompt:

<CodeBlock lang="tsx" code={`import { FileUpload } from '@usemotif/ui';

<FileUpload accept=".pdf" label="Drop your CV here (PDF)" onFiles={([file]) => setCv(file)} />`} />
