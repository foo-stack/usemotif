# MultiSelect

<Lede>
  MultiSelect picks any number of options from a list. Each pick becomes a chip in the field, with
  a button to remove it, and typing in the field filters the list.
</Lede>

<ArticleMeta />

## What it is

The headless [MultiSelect](/headless/selection/multi-select) behaviour with a themed field, chips,
and list. Clicking an option toggles it: a picked option is removed again. Backspace in an empty
input removes the last chip. Once `maxSelections` is reached, further picks do nothing.

The kit field is a wrapping row in `surface.raised` with a `border.default` border, at least 40px
tall, holding the chips and a borderless text input. Each chip is a small `surface.muted` pill
with a remove button labelled "Remove". In the listbox, picked options carry a check mark in
`action.primary` and the highlighted row takes `surface.interactive`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { MultiSelect } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { MultiSelect } from '@usemotif/ui';

const langs = [
  { value: 'ts', label: 'TypeScript' },
  { value: 'rs', label: 'Rust' },
  { value: 'go', label: 'Go' },
];

<MultiSelect options={langs} defaultValue={['ts']} onValueChange={setLangs} />`} />

Controlled, capped at three:

<CodeBlock lang="tsx" code={`import { MultiSelect } from '@usemotif/ui';

<MultiSelect
  options={tags}
  value={picked}
  onValueChange={setPicked}
  maxSelections={3}
  placeholder="Add a tag"
  width={360}
/>`} />
