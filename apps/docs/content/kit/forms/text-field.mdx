# TextField

<Lede>
  TextField is the kit's text input. Pick a `size`, and set `invalid` to show the danger border and
  mark the field invalid for assistive technology.
</Lede>

<ArticleMeta />

## What it is

`TextField` is the `inputRecipe` from `@usemotif/recipes` applied to a `Box` rendered as an
`<input>`. It takes every input attribute (`value`, `onChange`, `placeholder`, `type`, and the
rest) and defaults `type` to `"text"`.

Put it inside [FormField](/kit/display/form-field) for the label, help text and error message:
FormField gives it an `id`, `aria-describedby`, and `aria-invalid` when there is an error.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { TextField } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { FormField, TextField } from '@usemotif/ui';

<FormField label="Email" error={error}>
  <TextField
    type="email"
    value={email}
    onChange={(e) => setEmail(e.currentTarget.value)}
    invalid={error !== undefined}
  />
</FormField>`} />
