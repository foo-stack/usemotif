# RangeSlider

<Lede>
  RangeSlider picks a span, such as a price range, with two thumbs on one track. The value is a
  `[low, high]` pair, and neither thumb can pass the other.
</Lede>

<ArticleMeta />

## What it is

The headless [RangeSlider](/headless/numeric/range-slider) behaviour with a themed track, fill,
and thumbs. Each thumb is its own `role="slider"`, and its `aria-valuemin` and `aria-valuemax`
follow the other thumb, so assistive tech reports the range each thumb can move in. Arrow keys
step a thumb; Home and End send it to its limit.

The kit paints a 6px rounded track in `surface.muted`, the segment between the thumbs in
`action.primary`, and two 16px round thumbs with an `action.primary` border, through the token CSS
variables. A disabled slider drops to half opacity.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { RangeSlider } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { RangeSlider } from '@usemotif/ui';

<RangeSlider defaultValue={[20, 80]} aria-label="Price range" onValueChange={setPrice} />`} />

Controlled, on a custom scale:

<CodeBlock lang="tsx" code={`import { RangeSlider } from '@usemotif/ui';

<RangeSlider
  value={hours}
  onValueChange={setHours}
  min={0}
  max={24}
  width={320}
  aria-label="Opening hours"
/>`} />
