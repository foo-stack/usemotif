# DatePicker

<Lede>
  DatePicker shows the chosen date on a button. Clicking it opens a calendar in a popover, and
  picking a day closes it again.
</Lede>

<ArticleMeta />

## What it is

The headless [DatePicker](/headless/datetime/date-picker) behaviour with a themed trigger,
popover, and calendar. The headless layer puts a [Calendar](/kit/forms/calendar) inside a
`Popover`, formats the trigger label with `Intl.DateTimeFormat` in the medium date style, and
closes the popover when a day is picked.

The kit supplies four defaults, and each one is used only when you leave the matching prop out:

- `triggerStyle` - a rounded button at least 180px wide, in `surface.default` with a
  `border.default` border
- `popoverStyle` - a raised, rounded panel with a shadow
- `style` - the calendar grid, 252px wide with no border of its own
- `renderDay` - the same themed day cells as the kit Calendar

`DatePickerProps` is the headless `DatePickerProps`, which extends `CalendarProps`, so every
calendar prop reaches the inner grid.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { DatePicker } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { DatePicker } from '@usemotif/ui';

<DatePicker placeholder="Pick a date" onValueChange={setDate} />`} />

Controlled, with past days disabled:

<CodeBlock lang="tsx" code={`import { DatePicker } from '@usemotif/ui';

<DatePicker
  value={due}
  onValueChange={setDue}
  isDisabled={(d) => d < startOfToday}
  weekStartsOn={1}
/>`} />
