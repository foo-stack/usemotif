# TimeInput

<Lede>
  TimeInput collects a time of day. It is a native `<input type="time">`, so the browser supplies
  the time UI, keyboard entry, and form submission.
</Lede>

<ArticleMeta />

## What it is

The headless [TimeInput](/headless/datetime/time-input) with a token theme. The headless layer
renders the native input, generates an `id` with `useId`, and sets `step` to 1 when `precision`
is `'second'` so the field shows seconds. The value is a string such as `'09:30'`, or
`'09:30:15'` at second precision.

The kit adds padding, a large radius, a `border.default` border, `surface.default` background, and
`text.default` colour, all through the token CSS variables. A `style` you pass merges over them.

Every standard input attribute except `type` passes through (`value`, `defaultValue`, `onChange`,
`min`, `max`, `step`, `name`, `required`, `disabled`, and the rest), as `TimeInputProps` is the
headless `TimeInputProps`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { TimeInput } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { TimeInput } from '@usemotif/ui';

<TimeInput defaultValue="09:30" onChange={(e) => setTime(e.currentTarget.value)} />`} />

To the second, inside business hours:

<CodeBlock lang="tsx" code={`import { TimeInput } from '@usemotif/ui';

<TimeInput precision="second" min="09:00" max="17:00" name="start" aria-label="Start time" />`} />

`type`, which is fixed to `time`.
