# SegmentedControl

<Lede>
  SegmentedControl picks one option from a short row of segments, such as a list or grid view. The
  selected segment lifts out of the track.
</Lede>

<ArticleMeta />

## What it is

A `role="radiogroup"` container in `surface.muted` holding one `role="radio"` button per option.
The selected segment takes `surface.raised`, a semibold weight, and a small shadow, and carries
`aria-checked`.

Only the selected segment is in the tab order. Left and Right arrows move the selection to the
previous or next enabled option, wrapping at the ends, and move focus with it. Disabled options
are skipped and render muted.

SegmentedControl has no headless component behind it: the selection and keyboard handling are
built in. With no `value` or `defaultValue`, the first option starts selected.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { SegmentedControl } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { SegmentedControl } from '@usemotif/ui';

<SegmentedControl
  aria-label="View"
  defaultValue="list"
  options={[
    { value: 'list', label: 'List' },
    { value: 'grid', label: 'Grid' },
  ]}
  onValueChange={setView}
/>`} />

Controlled, with a disabled option:

<CodeBlock lang="tsx" code={`import { SegmentedControl } from '@usemotif/ui';

<SegmentedControl
  aria-label="Range"
  value={range}
  onValueChange={setRange}
  options={[
    { value: 'day', label: 'Day' },
    { value: 'week', label: 'Week' },
    { value: 'year', label: 'Year', disabled: true },
  ]}
/>`} />
