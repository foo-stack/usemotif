# Checkbox

<Lede>
  Checkbox is a native `<input type="checkbox">` with a themed look. It is keyboard- and
  form-native, so it works controlled, uncontrolled, or inside a plain form submit.
</Lede>

<ArticleMeta />

## What it is

A `Box` rendered as an `<input type="checkbox">`, 18px square with a thin `border.strong` border
and a small radius. The native chrome is reset with `appearance: none`. When the input is checked,
the `_checked` pseudo-state fills it with `action.primary` and paints a white tick, all in CSS.

Every standard input attribute (`checked`, `defaultChecked`, `onChange`, `name`, `value`,
`disabled`, `required`, and the rest) passes through to the element. Checkbox omits `size`, and
replaces `style` with a version that merges over its own reset styles.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Checkbox } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Checkbox } from '@usemotif/ui';

<label>
  <Checkbox defaultChecked name="terms" /> I agree to the terms
</label>`} />

Controlled, and marked invalid when the form rejects it:

<CodeBlock lang="tsx" code={`import { Checkbox } from '@usemotif/ui';

<Checkbox
  checked={agreed}
  invalid={submitted && !agreed}
  onChange={(e) => setAgreed(e.currentTarget.checked)}
  aria-label="Agree to the terms"
/>`} />
