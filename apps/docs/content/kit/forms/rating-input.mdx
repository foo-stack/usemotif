# RatingInput

<Lede>
  RatingInput collects a score as a row of stars. Click a star to set the rating, or focus the row
  and use the arrow keys.
</Lede>

<ArticleMeta />

## What it is

The headless [RatingInput](/headless/numeric/rating-input) behaviour with themed stars. The
headless layer renders a `role="slider"` row with `aria-valuenow` from 0 to `count`. Arrow keys
step the value, Home sets it to 0, and End sets it to `count`.

The kit draws each item as a 22px star with a 4px gap. A filled star uses the `status.warning`
foreground colour; an empty one is an outline in `border.strong`.

With `allowHalf`, the value moves in steps of 0.5: arrow keys step by half a star, and clicking
the left half of a star sets the half value.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { RatingInput } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { RatingInput } from '@usemotif/ui';

<RatingInput defaultValue={3} aria-label="Rate this recipe" onValueChange={setStars} />`} />

Controlled, out of ten, with half steps:

<CodeBlock lang="tsx" code={`import { RatingInput } from '@usemotif/ui';

<RatingInput value={score} onValueChange={setScore} count={10} allowHalf aria-label="Score" />`} />
