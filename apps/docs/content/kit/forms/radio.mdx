# Radio

<Lede>
  Radio is a native `<input type="radio">` with a themed ring. Put a set of them inside a
  `RadioGroup` and they share one `name`, so the browser handles single selection and arrow keys.
</Lede>

<ArticleMeta />

## What it is

`Radio` is a `Box` rendered as an `<input type="radio">`, an 18px circle with a thin
`border.strong` border. The native chrome is reset with `appearance: none`. When checked, the
`_checked` pseudo-state fills the ring with `action.primary` and paints a white centre dot.

`RadioGroup` is a `role="radiogroup"` column with a small gap. Through context it gives each
`Radio` inside it:

- the group's `name`, or an id generated with `useId` when you leave `name` out
- `defaultChecked`, on the option whose `value` equals the group's `defaultValue`

Both are defaults only: a `name`, `checked`, or `defaultChecked` you pass on a `Radio` wins.
Selection stays native, so for controlled selection put `checked` and `onChange` on each `Radio`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Radio, RadioGroup } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Radio, RadioGroup } from '@usemotif/ui';

<RadioGroup name="plan" defaultValue="pro">
  <label>
    <Radio value="free" /> Free
  </label>
  <label>
    <Radio value="pro" /> Pro
  </label>
</RadioGroup>`} />

Controlled, one `checked` per option:

<CodeBlock lang="tsx" code={`import { Radio, RadioGroup } from '@usemotif/ui';

<RadioGroup name="size">
  {['s', 'm', 'l'].map((s) => (
    <label key={s}>
      <Radio value={s} checked={size === s} onChange={() => setSize(s)} /> {s.toUpperCase()}
    </label>
  ))}
</RadioGroup>`} />
