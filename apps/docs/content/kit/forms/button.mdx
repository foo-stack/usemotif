# Button

<Lede>
  Button is the kit's action control. Choose an `intent` and a `size`; the colours come from the
  theme's `action` and `surface` tokens, and hover and press dim it slightly.
</Lede>

<ArticleMeta />

## What it is

`Button` is `styled(Pressable, buttonRecipe)`: the `buttonRecipe` from `@usemotif/recipes` applied
to a `Pressable`. It renders a `<button type="button">`, mirrors `disabled` to `aria-disabled`, and
calls `onPress` on click.

Because it is a styled `Pressable`, it takes every `Pressable` prop alongside its variants,
including the style props for one-off adjustments.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Button } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Button } from '@usemotif/ui';

<Button onPress={save}>Save</Button>
<Button intent="neutral" size="sm" onPress={cancel}>Cancel</Button>
<Button intent="danger" disabled={busy} onPress={remove}>Delete</Button>`} />
