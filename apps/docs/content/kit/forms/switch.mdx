# Switch

<Lede>
  Switch is an on/off toggle for settings that apply straight away. It is a native checkbox input
  announced as a switch, so it works with keyboards, forms, and screen readers as is.
</Lede>

<ArticleMeta />

## What it is

A `Box` rendered as an `<input type="checkbox" role="switch">`, 44 by 24px with a fully rounded
track in `border.strong`. The thumb is a white circle painted as a background image. When checked,
the `_checked` pseudo-state turns the track `action.primary` and moves the thumb to the right edge,
with a 150ms transition.

Every standard input attribute (`checked`, `defaultChecked`, `onChange`, `name`, `disabled`, and
the rest) passes through to the element. Switch omits `size`, and replaces `style` with a version
that merges over its own reset styles.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Switch } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Switch } from '@usemotif/ui';

<label>
  <Switch defaultChecked onChange={(e) => save(e.currentTarget.checked)} /> Email notifications
</label>`} />

Controlled:

<CodeBlock lang="tsx" code={`import { Switch } from '@usemotif/ui';

<Switch
  checked={darkMode}
  onChange={(e) => setDarkMode(e.currentTarget.checked)}
  aria-label="Dark mode"
/>`} />

`SwitchProps` also accepts every `InputHTMLAttributes<HTMLInputElement>` attribute except `size`.
`type` is set to `checkbox` and `role` to `switch`.
