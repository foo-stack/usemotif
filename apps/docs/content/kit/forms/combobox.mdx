# Combobox

<Lede>
  Combobox is a text input with a suggestion list. Typing narrows the list, and picking an option
  fills the input. `Search` is the same control framed as site search.
</Lede>

<ArticleMeta />

## What it is

`Combobox` is the headless [Combobox](/headless/selection/combobox) behaviour with a themed input
and list. The headless layer gives the input `role="combobox"`, filters the options with a
case-insensitive match on their labels, and handles keyboard navigation in the listbox.

`Search` wraps the headless [Search](/headless/selection/search) instead, which renders the same
combobox inside a `role="search"` landmark. The two take the same props.

The kit input is a rounded field in `surface.raised` with a `border.default` border. The listbox
is a raised panel up to 260px tall that scrolls; the highlighted row takes `surface.interactive`
and the selected row is bold.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Combobox, Search } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Combobox } from '@usemotif/ui';

const frameworks = [
  { value: 'react', label: 'React' },
  { value: 'vue', label: 'Vue' },
  { value: 'svelte', label: 'Svelte' },
];

<Combobox options={frameworks} defaultValue="react" onValueChange={setFramework} />`} />

As site search:

<CodeBlock lang="tsx" code={`import { Search } from '@usemotif/ui';

<Search options={pages} onValueChange={openPage} placeholder="Search docs" />`} />
