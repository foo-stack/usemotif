# ColorPicker

<Lede>
  ColorPicker picks a colour by hue, saturation, and brightness, and reports it as a CSS string in
  hex, rgb, or hsl.
</Lede>

<ArticleMeta />

## What it is

The headless [ColorPicker](/headless/specialized/color-picker) behaviour inside a themed card. The
headless layer renders a saturation and value plane, a hue slider, an alpha slider when
`allowAlpha` is on and the format is not hex, and a toggle between the `formats`. Arrow keys move
the plane's thumb, Shift with an arrow takes larger steps, and the sliders use the standard slider
keys.

The kit lays the parts out in a column inside a rounded card in `surface.default` with a
`border.default` border. The plane is 220 by 150px, the sliders 220px wide and 12px tall, and the
plane's thumb a 14px white ring.

The kit sets the per-part styles itself, so `ColorPickerProps` omits the headless `style`,
`saturationValueStyle`, `saturationValueThumbStyle`, `hueSliderStyle`, and `alphaSliderStyle`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { ColorPicker } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { ColorPicker } from '@usemotif/ui';

<ColorPicker defaultValue="#3b82f6" onValueChange={setBrand} />`} />

Controlled, in rgb with an alpha slider:

<CodeBlock lang="tsx" code={`import { ColorPicker } from '@usemotif/ui';

<ColorPicker value={color} onValueChange={setColor} format="rgb" allowAlpha />`} />
