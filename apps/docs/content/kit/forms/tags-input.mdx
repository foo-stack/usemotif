# TagsInput

<Lede>
  TagsInput is a field of removable chips. Type and press Enter or a comma to add one, paste a list
  to add several, and press Backspace to remove the last.
</Lede>

<ArticleMeta />

## What it is

The headless [TagsInput](/headless/selection/tags-input) in a bordered `surface.raised` field.
Each tag is a [Chip](/kit/display/chip) whose remove button is named after it ("Remove react"),
and suggestions open in the same themed list as [Combobox](/kit/forms/combobox).

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

## Usage

<CodeBlock lang="tsx" code={`import { TagsInput } from '@usemotif/ui';

<TagsInput
  aria-label="Topics"
  defaultValue={['react']}
  suggestions={['react', 'react-native', 'typescript']}
/>`} />
