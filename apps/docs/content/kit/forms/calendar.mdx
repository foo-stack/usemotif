# Calendar

<Lede>
  Calendar is an always-visible month grid for picking a day. Click a day, or move through the
  grid with the keyboard and press Enter.
</Lede>

<ArticleMeta />

## What it is

The headless [Calendar](/headless/datetime/calendar) behaviour with a themed surface and day
cells. The headless layer renders a focusable `role="grid"`, owns each cell's `gridcell` role and
`aria-selected`, and handles the keyboard: arrows move a day, PageUp and PageDown move a month,
Home and End jump within the week, and Enter or Space selects. Weekday and month labels follow
`locale`.

The kit grid is a 280px raised panel with a `border.default` border and rounded corners. Each day
is painted by a default `renderDay`:

- the selected day fills with `action.primary`, its number in `text.inverse`
- today gets an `action.primary` ring
- days outside the month and disabled days render muted, disabled ones at half opacity

`CalendarProps` is the headless `CalendarProps`, so every headless prop reaches the kit component.
A `style` you pass merges over the kit's grid style, and a `renderDay` you pass replaces the
themed cell entirely.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Calendar } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Calendar } from '@usemotif/ui';

<Calendar defaultValue={new Date()} onValueChange={setDate} />`} />

Weeks starting on Monday, with weekends disabled:

<CodeBlock lang="tsx" code={`import { Calendar } from '@usemotif/ui';

<Calendar
  value={date}
  onValueChange={setDate}
  weekStartsOn={1}
  locale="en-GB"
  isDisabled={(d) => d.getDay() === 0 || d.getDay() === 6}
/>`} />
