# Slider

<Lede>
  Slider picks one number from a range by dragging a thumb along a track or pressing the arrow
  keys. Set `min`, `max`, and `step`, and the value snaps to the step.
</Lede>

<ArticleMeta />

## What it is

The headless [Slider](/headless/numeric/slider) behaviour with a themed track, fill, and thumb.
The headless layer renders `role="slider"` with `aria-valuenow`, handles pointer dragging, and
maps the arrow keys, Home, End, PageUp, and PageDown to value changes.

The kit paints a 6px rounded track in `surface.muted`, a fill in `action.primary`, and a 16px
round thumb with an `action.primary` border, all through the token CSS variables. A disabled
slider drops to half opacity. The kit slider is always horizontal: it sets its own track, fill,
and thumb styles and takes a `width` instead.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Slider } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Slider } from '@usemotif/ui';

<Slider defaultValue={40} aria-label="Volume" onValueChange={setVolume} />`} />

Controlled, with a custom range and step:

<CodeBlock lang="tsx" code={`import { Slider } from '@usemotif/ui';

<Slider
  value={opacity}
  onValueChange={setOpacity}
  min={0}
  max={1}
  step={0.05}
  width={320}
  aria-label="Opacity"
/>`} />
