# AlertDialog

<Lede>
  AlertDialog guards a destructive or irreversible action. It looks like a Modal but announces
  itself as an `alertdialog`, and a click on the scrim does not close it: the user confirms or
  cancels.
</Lede>

<ArticleMeta />

## What it is

The headless [AlertDialog](/headless/overlay/alert-dialog), a Dialog whose root defaults its role
to `alertdialog` and whose content defaults `dismissOnScrimClick` to `false`. Escape still closes
it. Focus is trapped inside and restored to the trigger on close.

The kit surface is a centered `surface.raised` card, 280px to 420px wide, that fades and scales in
on open and back out on close. Unlike [Modal](/kit/overlay/modal), it does not change into a sheet
on narrow viewports.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { AlertDialog } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<AlertDialog.Root>
  <AlertDialog.Trigger>
    <Button>Delete</Button>
  </AlertDialog.Trigger>
  <AlertDialog.Content>
    <AlertDialog.Title>Title</AlertDialog.Title>
    <AlertDialog.Description>Supporting copy.</AlertDialog.Description>
    <AlertDialog.Close>
      <Button>Cancel</Button>
    </AlertDialog.Close>
  </AlertDialog.Content>
</AlertDialog.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { AlertDialog } from '@usemotif/ui';
import { Button, HStack } from 'usemotif';

<AlertDialog.Root>
  <AlertDialog.Trigger>
    <Button intent="danger">Delete account</Button>
  </AlertDialog.Trigger>
  <AlertDialog.Content>
    <AlertDialog.Title>Delete account?</AlertDialog.Title>
    <AlertDialog.Description>This cannot be undone.</AlertDialog.Description>
    <HStack gap="$space.2" justifyContent="flex-end">
      <AlertDialog.Close>
        <Button variant="ghost">Cancel</Button>
      </AlertDialog.Close>
      <AlertDialog.Close>
        <Button intent="danger" onClick={deleteAccount}>Delete</Button>
      </AlertDialog.Close>
    </HStack>
  </AlertDialog.Content>
</AlertDialog.Root>`} />

`AlertDialog.Description` takes the same single `children` prop and renders it in the `sm` size
and `text.muted`. Both are bound into the surface's `aria-labelledby` and `aria-describedby`.
