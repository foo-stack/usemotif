# Menu

<Lede>
  Menu opens a list of actions under a button: rename, duplicate, archive. Choosing an item runs its
  `onSelect`, closes the menu, and returns focus to the trigger.
</Lede>

<ArticleMeta />

## What it is

The headless [Menu](/headless/menu/menu) with a themed panel and rows. The trigger gets
`aria-haspopup="menu"` and `aria-expanded`, and opens on click or on ArrowDown, Enter, or Space.
When it opens, focus moves to the first enabled item. ArrowDown and ArrowUp move between enabled
items and wrap, Home and End jump to the ends, Enter or Space activates, and Escape or a click
outside closes the menu.

The kit panel is a `surface.raised` card at least 180px wide with a `border.default` border. Each
item is the focusable element itself, so it takes `surface.interactive` on both hover and keyboard
focus. A disabled item renders in `text.muted`.

## Usage

<CodeBlock lang="tsx" code={`import { Menu } from '@usemotif/ui';
import { Button } from 'usemotif';

<Menu.Root>
  <Menu.Trigger>
    <Button variant="outline">Actions</Button>
  </Menu.Trigger>
  <Menu.Content>
    <Menu.Item onSelect={rename}>Rename</Menu.Item>
    <Menu.Item onSelect={duplicate}>Duplicate</Menu.Item>
    <Menu.Separator />
    <Menu.Item disabled>Archive</Menu.Item>
  </Menu.Content>
</Menu.Root>`} />

projects the item semantics onto its own themed row.

### Menu.Separator

<ApiSignature
  name="Menu.Separator"
  status="stable"
  signature={`function Menu.Separator(): JSX.Element`}
/>

A `role="separator"` hairline in `border.default`. It takes no props.

### Menu.Sub, Menu.SubTrigger, Menu.SubContent

A submenu. `Menu.SubTrigger` is themed like an item with a trailing chevron and opens on hover,
click, Arrow Right, Enter or Space; `Menu.SubContent` is the same raised card as the menu.
Arrow Left or Escape closes it, and choosing an item inside closes the whole menu. The kit's
Menu and ContextMenu share these parts.

### Menu.CheckboxItem, Menu.RadioGroup, Menu.RadioItem, Menu.Label

Stateful rows with a fixed indicator column: a check on a checked checkbox item, a dot on the
selected radio item, so labels line up either way. `Menu.Label` is a small muted heading the
arrow keys skip. The props are the headless ones without `style` and `asChild`; see
[Menu (headless)](/headless/menu/menu#menucheckboxitem-menuradiogroup-menuradioitem-menulabel).

  <Menu.RadioItem value="date">Date modified</Menu.RadioItem>
</Menu.RadioGroup>`} />
