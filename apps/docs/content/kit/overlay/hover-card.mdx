# HoverCard

<Lede>
  HoverCard shows a preview when the pointer rests on a link or the link takes focus - a profile, a
  page summary, a quick action. Unlike a tooltip, the card can hold links and buttons, and it stays
  open while the pointer or focus moves into it.
</Lede>

<ArticleMeta />

## What it is

The headless [HoverCard](/headless/overlay/hover-card) with a themed card. The headless layer
opens the card after `openDelay`, closes it `closeDelay` after the pointer or focus leaves both the
trigger and the card, and closes it on Escape. The card is a non-modal `role="dialog"`, so give it
an `aria-label`.

The kit card is a `surface.raised` box, 240px to 360px wide, with a `border.default` border and
`lg` radius.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { HoverCard } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<HoverCard.Root>
  <HoverCard.Trigger>
    <a href="/u/jane">@jane</a>
  </HoverCard.Trigger>
  <HoverCard.Content aria-label="Preview">Card content</HoverCard.Content>
</HoverCard.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { HoverCard } from '@usemotif/ui';

<HoverCard.Root openDelay={400} placement="top">
  <HoverCard.Trigger>
    <a href="/u/jane">@jane</a>
  </HoverCard.Trigger>
  <HoverCard.Content aria-label="Jane's profile">
    <ProfileSummary id="jane" />
  </HoverCard.Content>
</HoverCard.Root>`} />

## API

### HoverCard.Root

The headless `HoverCard.Root`. Open state is internal; there is no controlled mode.
