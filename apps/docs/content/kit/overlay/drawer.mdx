# Drawer and Sheet

<Lede>
  Drawer is a modal panel anchored to one edge of the viewport. It slides in from its `side` when
  it opens and back out when it closes. Sheet is the same panel fixed to the bottom edge.
</Lede>

<ArticleMeta />

## What it is

The headless [Drawer](/headless/overlay/drawer) and [Sheet](/headless/overlay/sheet), both
side-anchored Dialogs: focus trap, scrim, and Escape or scrim-click dismissal. The two namespaces
share every part except `Content`, where Drawer takes a `side` and Sheet does not.

The kit panel is a `surface.raised` surface with a `border.muted` border. A left or right drawer is
360px wide (at most 90vw) and full height; a top or bottom one is full width. Only the corners that
face into the viewport are rounded. The slide runs through the active motion driver.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Drawer, Sheet } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Drawer.Root>
  <Drawer.Trigger>
    <Button>Open</Button>
  </Drawer.Trigger>
  <Drawer.Content side="right">
    <Drawer.Title>Title</Drawer.Title>
    <Drawer.Description>Supporting copy.</Drawer.Description>
    <Drawer.Close>
      <Button>Close</Button>
    </Drawer.Close>
  </Drawer.Content>
</Drawer.Root>`} />

`Sheet` has the same six parts: `Sheet.Root`, `Sheet.Trigger`, `Sheet.Content`, `Sheet.Title`,
`Sheet.Description`, and `Sheet.Close`.

## Usage

<CodeBlock lang="tsx" code={`import { Drawer } from '@usemotif/ui';
import { Button } from 'usemotif';

<Drawer.Root>
  <Drawer.Trigger>
    <Button>Menu</Button>
  </Drawer.Trigger>
  <Drawer.Content side="left">
    <Drawer.Title>Navigation</Drawer.Title>
    <NavLinks />
  </Drawer.Content>
</Drawer.Root>`} />

A bottom sheet of actions:

<CodeBlock lang="tsx" code={`import { Sheet } from '@usemotif/ui';
import { Button } from 'usemotif';

<Sheet.Root>
  <Sheet.Trigger>
    <Button>Share</Button>
  </Sheet.Trigger>
  <Sheet.Content>
    <Sheet.Title>Share this file</Sheet.Title>
    <Sheet.Description>Anyone with the link can view it.</Sheet.Description>
    <Sheet.Close>
      <Button>Done</Button>
    </Sheet.Close>
  </Sheet.Content>
</Sheet.Root>`} />

### Title, Description, and Close

`Drawer.Title` and `Sheet.Title` are the same component, as are the two `Description` parts. Each
takes a single `children` prop: the title renders in the `lg` size at semibold weight, the
description in the `sm` size and `text.muted`, and both bind into the panel's ARIA labelling.
