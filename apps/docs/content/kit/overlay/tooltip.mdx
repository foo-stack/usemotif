# Tooltip

<Lede>
  Tooltip shows a short label next to an element on hover or keyboard focus. It describes the
  element rather than adding to it, so keep the text brief and never put anything interactive
  inside.
</Lede>

<ArticleMeta />

## What it is

The headless [Tooltip](/headless/overlay/tooltip) with a themed bubble. The headless layer opens
the tip after `openDelay`, closes it after `closeDelay`, renders it in a portal with
`role="tooltip"`, and points the trigger's `aria-describedby` at it.

The kit bubble uses the inverse surface: `surface.inverse` behind `text.inverse`, in the `sm` size,
up to 240px wide, with `md` radius.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Tooltip } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Tooltip.Root>
  <Tooltip.Trigger>
    <Button>Hover me</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>Hint text</Tooltip.Content>
</Tooltip.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { Tooltip } from '@usemotif/ui';
import { IconButton } from 'usemotif';

<Tooltip.Root placement="top" openDelay={300}>
  <Tooltip.Trigger>
    <IconButton aria-label="Copy link">
      <CopyIcon />
    </IconButton>
  </Tooltip.Trigger>
  <Tooltip.Content>Copy link</Tooltip.Content>
</Tooltip.Root>`} />

For a row of tooltips, such as a toolbar's, wrap them in `Tooltip.Provider`: after the first one
opens, moving to a neighbour shows it at once instead of waiting the delay again. See the
[headless Tooltip](/headless/overlay/tooltip#tooltipprovider) for `skipDelayDuration`.

<CodeBlock lang="tsx" code={`<Tooltip.Provider>
  <HStack gap="$space.1">{tools}</HStack>
</Tooltip.Provider>`} />

## API

### Tooltip.Root

The headless `Tooltip.Root`. Open state is internal; there is no controlled mode.
