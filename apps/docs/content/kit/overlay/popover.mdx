# Popover

<Lede>
  Popover opens a small panel next to the button that triggered it. Use it for controls that belong
  to one spot on the page - a filter set, a share field, a short form - without taking over the
  screen the way a modal does.
</Lede>

<ArticleMeta />

## What it is

The headless [Popover](/headless/overlay/popover) with a themed panel. The headless layer
positions the panel against the trigger, wires `aria-expanded`, `aria-controls`, and
`aria-haspopup="dialog"` on the trigger, and closes on Escape or a click outside. It is non-modal:
focus stays where it was, and the page behind remains usable.

The kit panel is a `surface.raised` box, 200px to 320px wide, with a `border.default` border and
`lg` radius.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Popover } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Popover.Root>
  <Popover.Trigger>
    <Button>Open</Button>
  </Popover.Trigger>
  <Popover.Content>
    Panel content
    <Popover.Close>
      <Button>Done</Button>
    </Popover.Close>
  </Popover.Content>
</Popover.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { Popover } from '@usemotif/ui';
import { Button } from 'usemotif';

<Popover.Root>
  <Popover.Trigger>
    <Button variant="outline">Filters</Button>
  </Popover.Trigger>
  <Popover.Content placement="right">
    <FilterControls />
    <Popover.Close>
      <Button>Apply</Button>
    </Popover.Close>
  </Popover.Content>
</Popover.Root>`} />
