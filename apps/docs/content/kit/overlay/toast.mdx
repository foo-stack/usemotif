# Toast

<Lede>
  Toasts are short notices that appear in a corner and go away on their own: "Saved", "Link
  copied", "Upload failed". Mount `Toaster` once near the root of your app, then call `toast()` from
  any component below it.
</Lede>

<ArticleMeta />

## What it is

The headless [Toaster](/headless/feedback/toast) with themed cards. The headless layer holds the
queue, dismisses each toast after its `duration`, and gives each card its own live region: a
`'background'` toast is a polite `role="status"`, a `'foreground'` toast an assertive
`role="alert"`.

The kit renders the queue as a column fixed 16px from the bottom-right corner of the viewport.
Each toast is a `surface.raised` card, 260px to 380px wide, showing the `title` in semibold, the
`description` in `text.muted`, and the `action` node beneath them. The column itself lets clicks
through; only the cards are interactive.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Toaster, useToast } from '@usemotif/ui';`} />

## Usage

Wrap the app once:

<CodeBlock lang="tsx" code={`import { Toaster } from '@usemotif/ui';

<Toaster defaultDuration={4000}>
  <App />
</Toaster>`} />

Push a toast from any component inside it:

<CodeBlock lang="tsx" code={`import { useToast } from '@usemotif/ui';
import { Button } from 'usemotif';

function SaveButton() {
  const { toast } = useToast();
  return (
    <Button onPress={() => toast({ title: 'Saved', description: 'Your changes are live.' })}>
      Save
    </Button>
  );
}`} />

An error that stays until dismissed, with an action:

<CodeBlock lang="tsx" code={`const { toast, dismiss } = useToast();

const id = toast({
  title: 'Upload failed',
  type: 'foreground',
  duration: Infinity,
  action: <Button onPress={() => dismiss(id)}>Dismiss</Button>,
});`} />

`ThemedToasterProps` is the headless `ToasterProps` without `renderToasts` and `style`: the kit
supplies the list and its layout.
