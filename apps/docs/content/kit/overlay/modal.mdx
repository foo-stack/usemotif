# Modal

<Lede>
  Modal is the kit's dialog. It traps focus, closes on Escape or a scrim click, and labels itself
  from its title and description. On a narrow viewport the same modal presents as a bottom sheet,
  sharing one open state.
</Lede>

<ArticleMeta />

## What it is

The headless [Dialog](/headless/overlay/dialog) with a themed surface. `Modal.Content` wraps
[Adapt](/headless/overlay/adapt): above the `below` breakpoint (default `sm`) it renders a
centered dialog, and below it a drawer anchored to `side` (default `bottom`). The trigger, title,
description, and close parts work the same in both presentations.

The surface is a `surface.raised` card, 280px to 480px wide, with a `border.muted` border and
`lg` radius. It mounts with a short fade and upward slide through the active motion driver.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Modal } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Modal.Root>
  <Modal.Trigger>
    <Button>Open</Button>
  </Modal.Trigger>
  <Modal.Content>
    <Modal.Title>Title</Modal.Title>
    <Modal.Description>Supporting copy.</Modal.Description>
    <Modal.Close>
      <Button>Cancel</Button>
    </Modal.Close>
  </Modal.Content>
</Modal.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { Modal } from '@usemotif/ui';
import { Button, Input } from 'usemotif';

<Modal.Root>
  <Modal.Trigger>
    <Button>Rename project</Button>
  </Modal.Trigger>
  <Modal.Content>
    <Modal.Title>Rename project</Modal.Title>
    <Modal.Description>The new name shows everywhere the project is linked.</Modal.Description>
    <Input defaultValue="Atlas" />
    <Modal.Close>
      <Button>Save</Button>
    </Modal.Close>
  </Modal.Content>
</Modal.Root>`} />

Controlled, staying a dialog down to the `md` breakpoint:

<CodeBlock lang="tsx" code={`const [open, setOpen] = useState(false);

<Modal.Root open={open} onOpenChange={setOpen}>
  <Modal.Content below="md">
    <Modal.Title>Session expired</Modal.Title>
  </Modal.Content>
</Modal.Root>`} />

`Modal.Description` takes the same single `children` prop and renders it in the `sm` size and
`text.muted`. Both bind their generated ids into the surface's `aria-labelledby` and
`aria-describedby`.
