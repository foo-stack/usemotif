# CommandPalette

<Lede>
  CommandPalette is a search box for actions. The user opens it with a shortcut, types a few
  letters, and runs a command from the filtered list without reaching for the mouse.
</Lede>

<ArticleMeta />

## What it is

The headless [CommandPalette](/headless/menu/command-palette) rendered inside the headless
Dialog, so it traps focus and closes on Escape or a scrim click. The input is a
`role="combobox"` and the results a `role="listbox"`. ArrowDown and ArrowUp move the highlight,
Home and End jump to the ends, and Enter runs the highlighted command, which also closes the
palette.

Typing filters the `commands` by fuzzy match against each `label` and its `keywords`, best match
first. With an empty input the commands keep your order, grouped by `section`; commands without a
section fall under "Commands", and recently run commands are lifted to the top under "Recent".

The kit draws the whole surface: a `surface.raised` panel 560px wide (at most 92vw), a borderless
search input with a hairline beneath it, and command rows that show the command's `icon`, `label`,
and `shortcut`. The highlighted row takes `surface.interactive`; a disabled one renders in
`text.muted`.

A command with `children` opens a nested page. A breadcrumb above the input shows the trail, each
earlier level a button back to it, and Backspace on an empty input or Escape goes back one level.
Escape closes the palette only from the top level.

## Usage

<CodeBlock lang="tsx" code={`import { CommandPalette, useCommandPaletteShortcut, type Command } from '@usemotif/ui';
import { useCallback, useState } from 'react';

const commands: Command[] = [
  { id: 'new', label: 'New file', section: 'File', shortcut: ['Mod', 'N'], onSelect: newFile },
  { id: 'open', label: 'Open file', section: 'File', keywords: ['load'], onSelect: openFile },
  { id: 'theme', label: 'Toggle theme', section: 'View', onSelect: toggleTheme },
];

function Palette() {
  const [open, setOpen] = useState(false);
  const toggle = useCallback(() => setOpen((v) => !v), []);
  useCommandPaletteShortcut('mod+k', toggle);
  return <CommandPalette commands={commands} open={open} onOpenChange={setOpen} />;
}`} />

### useCommandPaletteShortcut

<ApiSignature

  params={[
    {

    },
    {
      name: 'handler',

The kit re-exports this hook from `@usemotif/headless`. The palette does not bind a shortcut on its
own: open it from the hook or from any button.
