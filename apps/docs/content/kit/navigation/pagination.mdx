# Pagination

<Lede>
  Pagination moves through numbered pages of results. It always shows the first and last page,
  a window of pages around the current one, and an ellipsis for the gaps. Seven pages or fewer are
  all shown.
</Lede>

<ArticleMeta />

## What it is

The headless [Pagination](/headless/navigation/pagination) with themed buttons. The headless layer
computes the page window, renders a `nav` landmark (labelled `Pagination` by default), disables
previous on the first page and next on the last, and clamps every move to `1` through `total`.
Pagination is controlled only: hold `page` in state and update it from `onPageChange`.

The kit draws each control as a 36px button with `md` radius: page numbers, `‹` and `›` for
previous and next, and a muted `...` for each gap. The current page fills with
`action.primary` and carries `aria-current="page"`; other pages take `surface.interactive` on
hover.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Pagination } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Pagination } from '@usemotif/ui';
import { useState } from 'react';

function Results() {
  const [page, setPage] = useState(1);
  return <Pagination page={page} total={20} onPageChange={setPage} />;
}`} />

Two pages either side of the current one:

<CodeBlock lang="tsx" code={`<Pagination page={page} total={50} siblings={2} onPageChange={setPage} aria-label="Search results" />`} />

With a page-size select, which moves to the page holding the reader's first visible row:

<CodeBlock lang="tsx" code={`<Pagination
  page={page}
  total={Math.ceil(rows.length / pageSize)}
  onPageChange={setPage}
  pageSize={pageSize}
  onPageSizeChange={(size, nextPage) => {
    setPageSize(size);
    setPage(nextPage);
  }}
/>`} />
