# TreeView

<Lede>
  TreeView shows a nested hierarchy, such as files and folders, where each branch expands and
  collapses and one node at a time is selected.
</Lede>

<ArticleMeta />

## What it is

The headless [TreeView](/headless/specialized/tree-view) with a themed surface and rows. It
renders `role="tree"` with a `role="treeitem"` per visible node, carrying `aria-level`,
`aria-expanded` on branches, `aria-selected`, and `aria-disabled`. The tree is one tab stop.
ArrowDown and ArrowUp move between visible nodes; ArrowRight expands a collapsed branch; ArrowLeft
collapses an open branch or moves to the parent; Enter or Space selects. A disabled node cannot be
selected.

The kit surface is a bordered, `lg`-radius box on `surface.raised`. Each row is indented 16px per
level and shows a disclosure chevron when the node has children, loaded or not. Clicking a row
selects it; clicking its chevron only toggles the branch. A branch whose children are loading
shows muted "Loading" text. The selected row fills with `action.primary` in
`text.inverse`, and a disabled row renders in `text.muted`.

## Usage

<CodeBlock lang="tsx" code={`import { TreeView, type TreeNode } from '@usemotif/ui';

const files: TreeNode[] = [
  {
    id: 'src',
    label: 'src',
    children: [
      { id: 'src/index.ts', label: 'index.ts' },
      { id: 'src/app.tsx', label: 'app.tsx' },
    ],
  },
  { id: 'package.json', label: 'package.json' },
];

<TreeView data={files} defaultExpanded={['src']} onValueChange={openFile} aria-label="Files" />`} />

Controlled selection:

<CodeBlock lang="tsx" code={`const [selected, setSelected] = useState<string>();

<TreeView data={files} value={selected} onValueChange={setSelected} aria-label="Files" />`} />
