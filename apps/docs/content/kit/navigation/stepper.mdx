# Stepper

<Lede>
  Stepper shows where someone is in a fixed sequence - a checkout, an onboarding flow, a setup
  wizard. It is an indicator: the steps display progress and are not clickable.
</Lede>

<ArticleMeta />

## What it is

The headless [Stepper](/headless/navigation/stepper) with themed steps. It renders an ordered
list, one item per step, and puts `aria-current="step"` on the active one. A step's status comes
from its own `status` field, except that the step whose `id` equals `current` is always `active`.
A step with no status is `pending`.

Each kit step is a 28px circle and a label. The circle shows the step number, a check mark when
complete, or `!` on error, and takes its colour from the status: `action.primary` when active,
the `status.success` tint when complete, the `status.danger` tint on error, and `surface.muted`
when pending. The active label is semibold.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Stepper } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Stepper } from '@usemotif/ui';

<Stepper
  current="ship"
  steps={[
    { id: 'cart', label: 'Cart', status: 'complete' },
    { id: 'ship', label: 'Shipping' },
    { id: 'pay', label: 'Payment' },
  ]}
/>`} />

Vertical, with a failed step:

<CodeBlock lang="tsx" code={`<Stepper
  orientation="vertical"
  steps={[
    { id: 'upload', label: 'Upload', status: 'complete' },
    { id: 'verify', label: 'Verify', status: 'error' },
    { id: 'publish', label: 'Publish' },
  ]}
/>`} />
