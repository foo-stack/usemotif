# Toolbar

<Lede>
  Toolbar groups a set of controls, such as formatting buttons, into one strip. Arrow keys move
  focus between the controls inside it.
</Lede>

<ArticleMeta />

## What it is

The headless [Toolbar](/headless/navigation/toolbar) on a themed surface. It renders a
`role="toolbar"` element with `aria-orientation`. ArrowRight and ArrowLeft (ArrowDown and ArrowUp
when vertical) move focus to the next or previous enabled button or focusable element and wrap;
Home and End jump to the first and last.

The kit surface is an inline-flex strip with 4px padding and gap, an `lg` radius, a
`border.default` border, and a `surface.default` background, read from the token CSS variables.
Put [Button](/components/interactive/button) or [IconButton](/components/interactive/icon-button) primitives
inside.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Toolbar } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Toolbar } from '@usemotif/ui';
import { IconButton } from 'usemotif';

<Toolbar aria-label="Formatting">
  <IconButton aria-label="Bold">
    <BoldIcon />
  </IconButton>
  <IconButton aria-label="Italic">
    <ItalicIcon />
  </IconButton>
  <IconButton aria-label="Underline">
    <UnderlineIcon />
  </IconButton>
</Toolbar>`} />
