# NavigationMenu

<Lede>
  NavigationMenu is a site's primary nav bar: a single row of links, with the page you are on
  marked and emphasized.
</Lede>

<ArticleMeta />

## What it is

The headless [NavigationMenu](/headless/menu/navigation-menu) in its flat, single-level mode. It
renders a `nav` landmark (labelled `Primary` by default) around a list, one list item per child,
and sets `aria-current="page"` on the item whose `id` matches `current`. The kit does not expose the
headless multi-level `items` tree.

Each kit item is an `a` when it has an `href` and a `button` otherwise. Items render in
`text.muted` and darken on hover; the current item turns `action.primary` at semibold weight.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { NavigationMenu } from '@usemotif/ui';`} />

<CodeBlock lang="tsx" code={`<NavigationMenu current="a">
  <NavigationMenu.Item id="a" href="/a">A</NavigationMenu.Item>
  <NavigationMenu.Item id="b" href="/b">B</NavigationMenu.Item>
</NavigationMenu>`} />

## Usage

<CodeBlock lang="tsx" code={`import { NavigationMenu } from '@usemotif/ui';

<NavigationMenu current="docs" aria-label="Main">
  <NavigationMenu.Item id="home" href="/">Home</NavigationMenu.Item>
  <NavigationMenu.Item id="docs" href="/docs">Docs</NavigationMenu.Item>
  <NavigationMenu.Item id="blog" href="/blog">Blog</NavigationMenu.Item>
</NavigationMenu>`} />
