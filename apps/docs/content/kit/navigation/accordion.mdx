# Accordion

<Lede>
  Accordion stacks sections that each open and close behind a header. In `single` mode opening one
  section closes the others; in `multiple` mode each section toggles on its own.
</Lede>

<ArticleMeta />

## What it is

The headless [Accordion](/headless/disclosure/accordion), a set of
[Collapsible](/kit/navigation/collapsible) items that share one open-state array. Each trigger is a
button with `aria-expanded` and `aria-controls`; each panel is a `role="region"` labelled by its
trigger. Clicking an open section's trigger closes it, in either mode.

The kit wraps the items in one bordered, rounded container and separates them with hairlines. A
trigger is a full-width button with a chevron on the right. When it opens, its text turns
`action.primary` and the chevron flips, driven by its own `aria-expanded` through the `_expanded`
style state. Panel content renders in the `sm` size and `text.muted`.

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Accordion } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Accordion.Root>
  <Accordion.Item value="a">
    <Accordion.Trigger>Header</Accordion.Trigger>
    <Accordion.Content>Panel</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>`} />

## Usage

<CodeBlock lang="tsx" code={`import { Accordion } from '@usemotif/ui';

<Accordion.Root type="single" defaultValue={['shipping']}>
  <Accordion.Item value="shipping">
    <Accordion.Trigger>Shipping</Accordion.Trigger>
    <Accordion.Content>Orders ship in 2 to 3 business days.</Accordion.Content>
  </Accordion.Item>
  <Accordion.Item value="returns">
    <Accordion.Trigger>Returns</Accordion.Trigger>
    <Accordion.Content>Return anything within 30 days.</Accordion.Content>
  </Accordion.Item>
</Accordion.Root>`} />

Several open at once, controlled:

<CodeBlock lang="tsx" code={`const [open, setOpen] = useState<string[]>([]);

<Accordion.Root type="multiple" value={open} onValueChange={setOpen}>
  {/* items */}
</Accordion.Root>`} />
