# Breadcrumb

<Lede>
  Breadcrumb shows where the current page sits in the site: each ancestor as a link, ending in the
  page itself as plain text.
</Lede>

<ArticleMeta />

## What it is

The headless [Breadcrumb](/headless/navigation/breadcrumb) with themed crumbs. It renders a `nav`
landmark (labelled `Breadcrumb` by default) around an ordered list, wraps each child in a list
item, and puts `aria-current="page"` on the last one. The separators between items are
`aria-hidden`.

A crumb with an `href` is a link in `text.muted` that darkens to `text.default` on hover. A crumb
without one is the current page, in `text.default` at medium weight. The default separator is a
muted chevron, and the trail renders at 14px.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Breadcrumb } from '@usemotif/ui';`} />

## Anatomy

<CodeBlock lang="tsx" code={`<Breadcrumb>
  <Breadcrumb.Item href="/">Root</Breadcrumb.Item>
  <Breadcrumb.Item>Current page</Breadcrumb.Item>
</Breadcrumb>`} />

## Usage

<CodeBlock lang="tsx" code={`import { Breadcrumb } from '@usemotif/ui';

<Breadcrumb>
  <Breadcrumb.Item href="/">Home</Breadcrumb.Item>
  <Breadcrumb.Item href="/library">Library</Breadcrumb.Item>
  <Breadcrumb.Item>Data</Breadcrumb.Item>
</Breadcrumb>`} />

With a custom separator and label:

<CodeBlock lang="tsx" code={`<Breadcrumb separator="/" aria-label="You are here">
  <Breadcrumb.Item href="/docs">Docs</Breadcrumb.Item>
  <Breadcrumb.Item>Install</Breadcrumb.Item>
</Breadcrumb>`} />
