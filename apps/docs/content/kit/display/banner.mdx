# Banner

<Lede>
  Banner is the page-level cousin of Alert: a full-width bar for announcements, with room for an
  action and a dismiss button. Its tint comes from the theme's `status` tokens.
</Lede>

<ArticleMeta />

## What it is

A `Box` styled by the `bannerRecipe` from `@usemotif/recipes`, laid out as a row: an optional
icon, a column with the `title` and body copy, an optional `action`, and, when `onDismiss` is
set, a `×` button labelled "Dismiss".

The role follows the intent. `warning` and `danger` banners render with `role="alert"`; the
other intents use `role="status"`.

Banner is presentational. Pressing the dismiss button calls `onDismiss` and nothing else - your
state decides whether the banner stays mounted.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Banner } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { useState } from 'react';
import { Banner } from '@usemotif/ui';

function MaintenanceNotice() {
  const [open, setOpen] = useState(true);
  if (!open) return null;
  return (
    <Banner
      intent="warning"
      title="Scheduled maintenance"
      onDismiss={() => setOpen(false)}
    >
      The dashboard will be read-only from 02:00 to 03:00 UTC.
    </Banner>
  );
}`} />

With an action:

<CodeBlock lang="tsx" code={`import { Banner } from '@usemotif/ui';
import { Button } from 'usemotif';

<Banner intent="info" title="A new version is available" action={<Button>Reload</Button>}>
  Reload to get the latest features.
</Banner>`} />
