# Skeleton

<Lede>
  Skeleton holds the place of content that is still loading. Size it like the content it stands in
  for, and the layout stays still when the real content arrives.
</Lede>

<ArticleMeta />

## What it is

A `Box` filled with the theme's `surface.muted` colour, with rounded corners and a gentle pulse.
Set `circle` for a fully rounded placeholder whose height tracks its width, such as an avatar.

Skeleton is decorative and renders with `aria-hidden`. Announce the loading state some other way,
for example with `aria-busy` on the region that is loading. The pulse runs through motif's
reduced-motion guard, so it stops under `prefers-reduced-motion`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Skeleton } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Skeleton } from '@usemotif/ui';

<Skeleton width={240} height={20} />
<Skeleton circle width={40} />`} />

A loading row in the shape of a profile:

<CodeBlock lang="tsx" code={`import { Skeleton } from '@usemotif/ui';
import { HStack, VStack } from 'usemotif';

<HStack gap="$space.3" alignItems="center" aria-busy>
  <Skeleton circle width={40} />
  <VStack gap="$space.2" flex={1}>
    <Skeleton width="40%" height={14} />
    <Skeleton width="70%" height={12} />
  </VStack>
</HStack>`} />

A paragraph's worth of text lines, sized from the type scale, the last one shorter:

<CodeBlock lang="tsx" code={`<Skeleton lines={3} width={320} />
<Skeleton lines={2} fontSize="$fontSizes.sm" />`} />
