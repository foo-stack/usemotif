# Separator

<Lede>
  Separator draws a one-pixel line between groups of content, in the theme's `border.default`
  colour, and tells assistive tech that it is a divider.
</Lede>

<ArticleMeta />

## What it is

A `Box` with `role="separator"` and a matching `aria-orientation`. Horizontal, it spans the full
width at a height of one pixel. Vertical, it is one pixel wide and stretches to the height of its
parent, so place it inside a flex row.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Separator } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Separator } from '@usemotif/ui';
import { Text, VStack } from 'usemotif';

<VStack gap="$space.3">
  <Text>Account</Text>
  <Separator />
  <Text>Billing</Text>
</VStack>`} />

Vertical, between items in a row:

<CodeBlock lang="tsx" code={`import { Separator } from '@usemotif/ui';
import { HStack, Text } from 'usemotif';

<HStack gap="$space.3">
  <Text>Docs</Text>
  <Separator orientation="vertical" />
  <Text>Blog</Text>
</HStack>`} />
