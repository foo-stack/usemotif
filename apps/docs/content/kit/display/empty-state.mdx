# EmptyState

<Lede>
  EmptyState fills the space where content would be: an empty inbox, a search with no results, a
  project with nothing in it yet. It says what is missing and offers the next step.
</Lede>

<ArticleMeta />

## What it is

A centered column composed from `Box` and `Text`. From top to bottom: an optional `icon` in the
muted text colour, the `title`, an optional `description` in smaller muted text, and an optional
`action` below them.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { EmptyState } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { EmptyState } from '@usemotif/ui';
import { Button } from 'usemotif';

<EmptyState
  icon={<InboxIcon />}
  title="No messages yet"
  description="When someone writes to you, it will show up here."
  action={<Button>Compose</Button>}
/>`} />

A search with no results:

<CodeBlock lang="tsx" code={`import { EmptyState } from '@usemotif/ui';

<EmptyState
  title={'No results for "' + query + '"'}
  description="Try a shorter search, or check the spelling."
/>`} />
