# Card

<Lede>
  Card is a raised-surface container: a rounded, bordered column on the theme's `surface.raised`
  colour. Pick an `elevation` and a `padding` and put your content inside.
</Lede>

<ArticleMeta />

## What it is

`Card` is `styled(Box, cardRecipe)`: the `cardRecipe` from `@usemotif/recipes` applied to a
`Box`. It is a flex column, so its children stack vertically.

`flat` draws a stronger border with no shadow; `raised` adds a soft box-shadow.

Because it is a styled `Box`, it accepts every `Box` style prop alongside its variants, so you can
set `gap`, a width, or a different background at the call site.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Card } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Card } from '@usemotif/ui';
import { Paragraph, Text } from 'usemotif';

<Card elevation="raised" padding="lg" gap="$space.2">
  <Text fontWeight="$fontWeights.semibold">Team plan</Text>
  <Paragraph>Unlimited projects and shared billing.</Paragraph>
</Card>`} />

Edge-to-edge content, such as an image, with padding on an inner box:

<CodeBlock lang="tsx" code={`import { Card } from '@usemotif/ui';
import { Box, Image, Text } from 'usemotif';

<Card padding="none" overflow="hidden">
  <Image src="/cover.jpg" alt="" width="100%" height={160} />
  <Box p="$space.4">
    <Text>Release notes</Text>
  </Box>
</Card>`} />

### Parts

`Card.Header`, `Card.Body`, `Card.Footer` and `Card.Media` lay out the usual card. Each part pads
itself, so compose them in a `padding="none"` card; Media runs edge to edge.

<CodeBlock lang="tsx" code={`import { Button, Card } from '@usemotif/ui';
import { Image } from 'usemotif';

<Card padding="none" overflow="hidden">
  <Card.Media>
    <Image src="/cover.jpg" alt="" width="100%" height={160} />
  </Card.Media>
  <Card.Header>Pro plan</Card.Header>
  <Card.Body>Everything in Team, plus audit logs.</Card.Body>
  <Card.Footer>
    <Button size="sm">Choose Pro</Button>
  </Card.Footer>
</Card>`} />

| Part | Layout |
| --- | --- |
| `Card.Header` | A row with a gap, semibold, padded at the top and sides |
| `Card.Body` | A column that grows to fill the card, padded on every side |
| `Card.Footer` | A row aligned to the end, for actions, padded at the bottom and sides |
| `Card.Media` | Unpadded, for an image or video at the card's edge |

Every part takes the `Box` props, so a one-off change is a style prop away.

### A clickable card

When the whole card is a link or a button, render it as one and set `interactive`. It gains a
pointer cursor, a stronger border and shadow on hover, and a focus ring for keyboard users.

<CodeBlock lang="tsx" code={`<Card as="a" href="/plans/pro" interactive>
  <Text fontWeight="$fontWeights.semibold">Pro plan</Text>
</Card>`} />

Keep other links and buttons out of an interactive card: a control nested inside another is not
reachable on its own.
