# Badge

<Lede>
  Badge is a small, fully rounded status pill. Choose an `intent` and a `size`; the colours come
  from the theme's `action` and `surface` tokens.
</Lede>

<ArticleMeta />

## What it is

`Badge` is the `badgeRecipe` from `@usemotif/recipes` applied to a `Box`. It renders an inline flex row, so an icon and a label sit side by side, and it never
wraps its text.

Because it is a styled `Box`, it accepts every `Box` style prop alongside its variants. Use them
for one-off adjustments at the call site.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Badge } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Badge } from '@usemotif/ui';

<Badge intent="success">Active</Badge>
<Badge intent="danger" size="md">Overdue</Badge>`} />

Next to a heading:

<CodeBlock lang="tsx" code={`import { Badge } from '@usemotif/ui';
import { HStack, Text } from 'usemotif';

<HStack gap="$space.2" alignItems="center">
  <Text fontWeight="$fontWeights.semibold">Billing</Text>
  <Badge intent="primary">New</Badge>
</HStack>`} />

A count. Past `max` (99 unless you set it) it reads as `99+`. A `label` gives screen readers the
meaning the number alone does not carry:

<CodeBlock lang="tsx" code={`<Badge intent="danger" count={120} label="120 unread messages" />`} />

A status dot. It has no text, so it always needs a `label`:

<CodeBlock lang="tsx" code={`<Badge intent="success" dot label="Online" />`} />
