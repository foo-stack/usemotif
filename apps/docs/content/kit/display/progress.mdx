# Progress

<Lede>
  Progress shows how far along a task is. Pass a number for a bar that fills to that point, or
  `null` when the length of the task is unknown.
</Lede>

<ArticleMeta />

## What it is

The headless [Progress](/headless/numeric/progress) behaviour with a themed track and fill. The
headless layer renders `role="progressbar"` with `aria-valuenow`; the kit paints an 8px rounded
track in the `surface.muted` colour and a fill in `action.primary`.

A numeric `value` fills the bar to `value / max` and eases to each new width. A `null` value
switches to an indeterminate sweep, which becomes a static partial bar under
`prefers-reduced-motion`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Progress } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Progress } from '@usemotif/ui';

<Progress value={70} aria-label="Uploading" />
<Progress value={null} aria-label="Loading" />`} />

Counting items instead of a percentage:

<CodeBlock lang="tsx" code={`import { Progress } from '@usemotif/ui';

<Progress value={filesDone} max={filesTotal} aria-label="Files uploaded" />`} />
