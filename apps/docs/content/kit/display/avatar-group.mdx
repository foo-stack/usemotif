# AvatarGroup

<Lede>
  AvatarGroup shows who is involved - a document's collaborators, a channel's members - as a row of
  overlapping avatars, collapsing the rest into a `+N` count.
</Lede>

<ArticleMeta />

## What it is

A row of [Avatar](/components/media/avatar) primitives, each overlapping the one before by about
a third of its width and ringed in the page surface colour so the edges read cleanly. The first
`max` entries render as avatars; any beyond that become one muted circle showing `+N`, labelled
"N more" for assistive tech.

Each avatar shows the image at `src` when one is given, and initials from `name` otherwise.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { AvatarGroup } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { AvatarGroup } from '@usemotif/ui';

<AvatarGroup
  avatars={[
    { name: 'Jane Doe', src: '/avatars/jane.jpg' },
    { name: 'Sam Lee' },
    { name: 'Ana Silva' },
    { name: 'Kofi Mensah' },
    { name: 'Lee Park' },
  ]}
  max={3}
  size="sm"
/>`} />
