# ProgressCircle

<Lede>
  ProgressCircle is the round sibling of Progress. Give it a `value` and the arc fills to it; pass
  `null` and a quarter arc spins until the work is done.
</Lede>

<ArticleMeta />

## What it is

A `role="progressbar"` element around an SVG ring, carrying the same ARIA as
[Progress](/kit/display/progress): `aria-valuenow`, `aria-valuemin` and `aria-valuemax` when the value
is known, and none of them when it is not. The track uses `surface.muted` and the arc
`action.primary.bg`, and the arc eases to each new value.

The indeterminate spin stops under `prefers-reduced-motion`, leaving a still quarter arc.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { ProgressCircle } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { ProgressCircle } from '@usemotif/ui';

<ProgressCircle value={70} aria-label="Uploading" />
<ProgressCircle value={null} size={24} thickness={3} aria-label="Loading" />`} />
