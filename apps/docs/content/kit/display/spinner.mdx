# Spinner

<Lede>
  Spinner says "working on it" when you cannot say how long it will take. One prop sets its size;
  its colours come from the theme.
</Lede>

<ArticleMeta />

## What it is

A round `Box` with a `border.muted` ring and an `action.primary` top edge, rotating on a
`keyframes` animation. It renders with `role="status"` and `aria-label="Loading"`. The rotation
runs through motif's reduced-motion guard, so it stops under `prefers-reduced-motion`.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Spinner } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Spinner } from '@usemotif/ui';

<Spinner size={24} />`} />

A more specific label, since the default is "Loading":

<CodeBlock lang="tsx" code={`import { Spinner } from '@usemotif/ui';
import { HStack, Text } from 'usemotif';

<HStack gap="$space.2" alignItems="center">
  <Spinner size={16} aria-label="Saving changes" />
  <Text>Saving</Text>
</HStack>`} />
