# Timeline

<Lede>
  Timeline lays out a sequence of events top to bottom: an order's progress, a deploy history, an
  audit log. Pass the events as data and it draws the markers and the line between them.
</Lede>

<ArticleMeta />

## What it is

A column composed from `Box` and `Text`, one row per item. Each row has a marker column - a dot,
then a connector line down to the next event, omitted after the last - beside the event's
`title`, its `time` in muted text, and its `description` underneath.

The dot takes the primary accent colour by default. Set an item's `status` to `success`,
`warning`, or `danger` to colour it from the theme's `status` tokens instead.

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Timeline } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Timeline } from '@usemotif/ui';

<Timeline
  items={[
    { id: 'placed', title: 'Order placed', time: '09:30', status: 'success' },
    { id: 'packed', title: 'Packed', time: '11:05', status: 'success' },
    {
      id: 'out',
      title: 'Out for delivery',
      time: '14:10',
      description: 'Expected before 18:00.',
    },
  ]}
/>`} />

### TimelineItem
