# Alert

<Lede>
  Alert is an inline message box. Pick an `intent` and it tints the background, border, and text
  from the theme's `status` tokens, so it reads correctly in light and dark.
</Lede>

<ArticleMeta />

## What it is

A `Box` with `role="alert"`, styled by the `alertRecipe` from `@usemotif/recipes`. It lays out an
optional leading icon beside a column holding a bold `title` and the body copy. Both text lines
take the intent's foreground colour, and so does the icon when it draws with `currentColor`.

Alert sits inside the content it describes. For a page-level announcement that spans the full
width and carries an action or a dismiss button, use [Banner](/kit/display/banner).

## Install

<CodeBlock lang="bash" code={`yarn add @usemotif/ui`} />

<CodeBlock lang="tsx" code={`import { Alert } from '@usemotif/ui';`} />

## Usage

<CodeBlock lang="tsx" code={`import { Alert } from '@usemotif/ui';

<Alert intent="danger" title="Payment failed">
  Update your card and try again.
</Alert>`} />

Every intent but `neutral` shows a matching status icon by default. Pass `icon` to replace it with
any node (an SVG that draws with `currentColor` picks up the intent colour), or `icon={null}` to
show none:

<CodeBlock lang="tsx" code={`import { Alert } from '@usemotif/ui';

<Alert intent="info" title="New billing page" icon={<InfoIcon />}>
  Invoices now live under Settings.
</Alert>`} />

Dismissible, with an action. The dismiss button and action area are the same ones
[Banner](/kit/display/banner) uses:

<CodeBlock lang="tsx" code={`import { Alert, Button } from '@usemotif/ui';

{visible ? (
  <Alert
    intent="warning"
    title="Card expiring"
    action={<Button size="sm" intent="neutral" onPress={openBilling}>Update</Button>}
    onDismiss={() => setVisible(false)}
  >
    Your card expires next month.
  </Alert>
) : null}`} />

    },
    {
      name: 'children',
      type: 'ReactNode',
      description: 'Body copy, rendered in a smaller size under the title.',
    },
    {
      name: 'action',
      type: 'ReactNode',
      description: 'A trailing action area, such as a link or a `Button`.',
    },
    {
      name: 'onDismiss',
      type: '() => void',
      description: 'Renders a `×` button labelled "Dismiss" that calls this. You own visibility: the Alert does not unmount itself.',
    },
  ]}
/>

`AlertIntent` is exported as the union of the five `intent` values.
