# Translating built-in labels

<Lede>
  Most of what a screen reader hears comes from your content. The rest comes from motif: the name
  of a pagination landmark, a dismiss button, a remove control, a list's empty message. Wrap your
  app in `MessagesProvider` to say those in your users' language.
</Lede>

<ArticleMeta />

## Provide translations

<CodeBlock lang="tsx" code={`import { MessagesProvider } from 'usemotif';

<MessagesProvider
  messages={{
    dismiss: 'Fermer',
    remove: 'Retirer',
    removeItem: (item) => \`Retirer \${item}\`,
    pagination: 'Pagination',
    noOptions: 'Aucune option',
  }}
>
  <App />
</MessagesProvider>`} />

Pass any of the keys below. Anything left out keeps its English default, and a nested
`MessagesProvider` layers over the one above it, so a section of the app can override a few labels
for itself. The provider works the same on the web and React Native, and covers `@usemotif/headless`,
the `@usemotif/ui` kit and the primitives.

A component's own prop still wins: `<Breadcrumb aria-label="Path">` keeps its label whatever the
catalogue says, and so do `placeholder`, `emptyMessage`, `removeLabel` and the rest where a
component has them.

## Read the catalogue

`useMessages()` returns the active catalogue, for a component of your own that should speak the
same language as motif's. `DEFAULT_MESSAGES` is the English catalogue, and `mergeMessages(base,
overrides)` is how providers combine.

| Key | English |
| --- | --- |
| `pagination` | Pagination |
| `previousPage` | Previous page |
| `nextPage` | Next page |
| `itemsPerPage` | Items per page |
| `perPage(count)` | `${count} / page` |
| `breadcrumb` | Breadcrumb |
| `showHiddenBreadcrumbs` | Show hidden breadcrumbs |
| `primaryNavigation` | Primary |
| `pinCharacter(position, length)` | `Character ${position} of ${length}` |
| `remove` | Remove |
| `removeItem(item)` | `Remove ${item}` |
| `dismiss` | Dismiss |
| `loading` | Loading |
| `loadingOptions` | Loading... |
| `noOptions` | No options |
| `searchPlaceholder` | Search... |

<Callout variant="info" title="Dates and numbers">
  Calendar and date picker labels come from `Intl.DateTimeFormat` with the component's `locale`
  prop, not from this catalogue. Pass `locale` there.
</Callout>
