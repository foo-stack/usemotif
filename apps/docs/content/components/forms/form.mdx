# Form

<Lede>
  Form puts the browser's own validation (`required`, `type="email"`, `pattern`, `min`) in front
  of a React 19 action, and shows every failure through the field's `FieldError` instead of the
  browser's bubble.
</Lede>

<ArticleMeta />

## Usage

<CodeBlock lang="tsx" code={`import { Button, Field, FieldError, Form, Input, Label } from '@usemotif/react';

async function signUp(data: FormData) {
  'use server';
  if (await emailTaken(data.get('email'))) return { errors: { email: 'Already registered' } };
}

<Form action={signUp}>
  <Field>
    <Label>Email</Label>
    <Input name="email" type="email" required />
    <FieldError />
  </Field>
  <Button type="submit">Sign up</Button>
</Form>`} />

## What happens on submit

1. Form checks every control's native constraints. Nothing is sent while any fails.
2. Each failing field turns invalid: its control gets `aria-invalid` and points `aria-describedby`
   at the error, and an empty `FieldError` shows the browser's message for it. Focus moves to the
   first invalid control.
3. From then on, a field rechecks as it's edited, and its message clears once it passes.
4. A submit that passes calls `onSubmit`, then runs `action` with the form's `FormData` as a React
   19 form action, so `useFormStatus` in a child reports it pending.
5. Errors the action returns, keyed by control `name`, land on those fields. Each clears on the
   field's first edit.

A message comes from the control's `validationMessage`, so it's the browser's wording in the
user's language. Set your own with `setCustomValidity`. A control outside any `Field` has no
`FieldError` to show, so for that one the browser shows its bubble.

## With useActionState

When the action's state lives in `useActionState`, pass its errors in:

<CodeBlock lang="tsx" code={`const [state, formAction] = useActionState(signUp, {});

<Form action={formAction} errors={state.errors}>
  {/* fields */}
</Form>`} />

`errors` is keyed by control `name`, like an action's result, and is shown from the first render,
so errors from a server render arrive already on their fields.
