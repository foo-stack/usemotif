# Stack

<Lede>
  Stack is the named flex container. It exists so common spacing setups read clearly at the call
  site without juggling `display`, `flexDirection`, and `gap` props every time.
</Lede>

<ComponentDemoStrip demo="stack" />

<ArticleMeta />

## What it is

A `<Box display="flex">` with a `direction` prop. Stack composes through Box, so every style prop,
every responsive key, every pseudo-state applies - `gap` is the prop you reach for most.

## Install

`Stack` is exported from `usemotif`. No separate install.

<CodeBlock lang="tsx" code={`import { Stack } from 'usemotif';`} />

## API

<ApiSignature
  name="Stack"
  status="stable"
  signature={`function Stack(props: StackProps): JSX.Element`}
  params={[

      type: '\"column\" | \"row\" | \"column-reverse\" | \"row-reverse\"',

    },
    {

      type: 'number',
      description: 'Seconds between the entry animations of direct children, so children with `enterStyle` arrive in a wave. Added to each child\'s own delay. Collapses to `0` under reduced motion on web.',
    },
    {
      name: 'staggerFrom',
      type: '\"first\" | \"last\" | \"center\" | number',
      default: '\"first\"',
      description: 'Where the wave starts. Each child waits `stagger` times its distance from that child; a number names a child index.',
    },
    {
      name: '...BoxProps',
      type: 'BoxProps',
      description: 'Every prop Box accepts - minus `display` and `flexDirection`, which Stack manages.',
    },
  ]}
/>

`gap`, `alignItems`, `justifyContent`, `flexWrap`, every other flex-related style prop comes from
Box. They work normally.

## Examples

Simple vertical stack:

<CodeBlock lang="tsx" code={`<Stack gap="$4">
  <Heading>Title</Heading>
  <Text>Body copy.</Text>
  <Button>Continue</Button>
</Stack>`} />

Horizontal row with the `direction` prop:

<CodeBlock lang="tsx" code={`<Stack direction="row" gap="$2" alignItems="center">
  <Avatar src={user.avatar} />
  <Text>{user.name}</Text>
</Stack>`} />

For horizontal layouts you reach for often, the `HStack` shorthand reads more clearly:

<CodeBlock lang="tsx" code={`<HStack gap="$2" alignItems="center">
  <Avatar src={user.avatar} />
  <Text>{user.name}</Text>
</HStack>`} />

Responsive direction - column on phones, row on desktops:

<CodeBlock lang="tsx" code={`<Stack direction={{ base: 'column', md: 'row' }} gap="$4">
  <Image />
  <Box>
    <Heading>Heading</Heading>
    <Text>Body</Text>
  </Box>
</Stack>`} />

<Callout variant="info" title="Related">
  [HStack](/components/layout/hstack) and [VStack](/components/layout/vstack) are direction-fixed
  shorthands. [Wrap](/components/layout/wrap) is a Stack-like container with `flex-wrap: wrap`.
</Callout>

Children that enter in a wave from the middle outwards:

<CodeBlock lang="tsx" code={`<HStack gap="$2" stagger={0.05} staggerFrom="center">
  {cards.map((card) => (
    <Box key={card.id} enterStyle={{ opacity: 0, transform: 'translateY(8px)' }}>
      {card.title}
    </Box>
  ))}
</HStack>`} />
