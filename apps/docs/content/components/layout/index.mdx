# Layout

<Lede>
  The spatial primitives. Box is the atom - every other layout component is a `<Box>` wearing a
  different name. Reach for the named primitive when it reads more clearly at the call site.
</Lede>

<ArticleMeta />

## The pieces

| Component | Use it for |
| --- | --- |
| [Box](/components/layout/box) | The styling atom. Any styled, theme-aware container. |
| [Stack](/components/layout/stack) | A flex container with consistent `gap`. Column by default. |
| [HStack](/components/layout/hstack) | Stack, horizontal. The most common stack shape. |
| [VStack](/components/layout/vstack) | Stack, vertical. Reads more clearly than `Stack` with no `direction`. |
| [Container](/components/layout/container) | Establishes a container-query context for `@bp` responsive keys. |
| [Center](/components/layout/center) | Flex container that centres on both axes. |
| [Flex](/components/layout/flex) | Bare `display: flex` without Stack's gap conventions. |
| [Grid](/components/layout/grid) | CSS Grid container with a uniform-column shorthand. |
| [Wrap](/components/layout/wrap) | Flex container with `flex-wrap: wrap` - tag lists, chip rows. |
| [ZStack](/components/layout/zstack) | Stack along the z-axis. Children share one grid cell. |
| [AspectRatio](/components/layout/aspect-ratio) | Wrap a child in a fixed width-to-height ratio. |
| [Spacer](/components/layout/spacer) | Eats the available main-axis space inside a flex container. |
| [SafeArea](/components/layout/safe-area) | No-op on web; wraps `SafeAreaView` on native. |
| [TitleBar](/components/layout/title-bar) | A custom desktop window title bar that drags the window. |

## Why so many

Most of these are sugar over `Box`. A `Center` is `<Box display="flex" alignItems="center"
justifyContent="center">`. A `Stack` is `<Box display="flex" gap=...>` with a `direction` prop. The
sugar exists because call sites read more clearly with names - and because compiled output costs
the same either way.

`Box` is always available when the named primitive does not fit. Skip the named primitive if you
need an unusual layout; the sugar is convention, not constraint.
