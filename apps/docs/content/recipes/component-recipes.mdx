# Component recipes

<Lede>
  `@usemotif/recipes` ships the variant configs for the components you build on every project -
  Button, Card, Badge, Input - and for the kit's display components - Alert, Banner, Chip, Stat - as
  plain `styled()` data. Pass one to `styled()` over any primitive and you have a themed,
  variant-driven component. No new runtime, no opinion you can't override.
</Lede>

<ArticleMeta />

## What they are

A recipe is a `StyledConfig` object - the same shape you pass to `styled()` by hand. Every colour is
a semantic token reference, so a recipe re-themes itself in light and dark with no extra work, and
any style prop you pass at the call site still wins over the recipe.

<CodeBlock lang="bash" code={`npm install @usemotif/recipes`} />

<Callout variant="info" title="Interaction can live in the recipe - or at the call site">
  A `styled()` layer carries pseudo-states (`_hover`, `_focus`, ...) and motion (`transition`,
  `enterStyle`) alongside static styles, so a recipe can bake in its own hover, focus ring, or press
  feedback - the Button recipe below does. Call-site props still win, and pseudo bags deep-merge, so
  a one-off `_hover` _extends_ the recipe's rather than replacing it. The `@usemotif/ui` kit goes
  further, wrapping these recipes into install-and-go components.
</Callout>

## Button

`intent` (`primary` · `danger` · `success` · `neutral` · `ghost`) × `size` (`sm` · `md` · `lg`).

<CodeBlock lang="tsx" code={`import { styled, Pressable } from 'usemotif';
import { buttonRecipe } from '@usemotif/recipes';

const Button = styled(Pressable, buttonRecipe);

// themed + sized + hover/press feedback out of the box

<Button intent="primary" size="lg">
  Save
</Button>
<Button intent="ghost">Cancel</Button>

// the recipe's hover is built in; a call-site \_hover extends it (deep-merge)

<Button intent="primary" _hover={{ outline: '2px solid' }}>
  Save
</Button>`} />

## Card

`elevation` (`flat` · `raised`) × `padding` (`none` · `sm` · `md` · `lg`).

<CodeBlock lang="tsx" code={`import { styled, Box } from 'usemotif';
import { cardRecipe } from '@usemotif/recipes';

const Card = styled(Box, cardRecipe);

<Card elevation="raised" padding="lg">
  <Heading>Title</Heading>
  <Paragraph>Body copy.</Paragraph>
</Card>`} />

## Badge

A status pill - `intent` (`neutral` · `primary` · `danger` · `success`) × `size` (`sm` · `md`).

<CodeBlock lang="tsx" code={`import { styled, Box } from 'usemotif';
import { badgeRecipe } from '@usemotif/recipes';

const Badge = styled(Box, badgeRecipe);

<Badge intent="success">Active</Badge>
<Badge intent="danger" size="md">Overdue</Badge>`} />

## Input

`size` (`sm` · `md` · `lg`) and an `invalid` boolean for form validation.

<CodeBlock lang="tsx" code={`import { styled, Input } from 'usemotif';
import { inputRecipe } from '@usemotif/recipes';

const TextField = styled(Input, inputRecipe);

<TextField size="md" placeholder="you@example.com" />
<TextField invalid={hasError} aria-invalid={hasError} />

// focus ring at the call site

<TextField _focus={{ borderColor: '$colors.action.primary.bg' }}
           transition="border-color 150ms ease" />`} />

## Alert

A message box tinted by `intent` (`neutral` · `info` · `success` · `warning` · `danger`), with the
surface, border, and text colours all drawn from the semantic `status` tokens.

<CodeBlock lang="tsx" code={`import { styled, Box } from 'usemotif';
import { alertRecipe } from '@usemotif/recipes';

const Alert = styled(Box, alertRecipe);

<Alert intent="danger" role="alert">
  Payment failed. Update your card and try again.
</Alert>`} />

## Banner

A full-width notice strip with the same `intent` scale as Alert and a bottom rule in the intent's
border colour.

<CodeBlock lang="tsx" code={`import { styled, Box } from 'usemotif';
import { bannerRecipe } from '@usemotif/recipes';

const Banner = styled(Box, bannerRecipe);

<Banner intent="info" role="status">Maintenance on Sunday from 02:00 UTC.</Banner>`} />

## Chip

A compact pill - `intent` (`neutral` · `primary`), plus two boolean variants that tighten the
padding: `withIcon` on the leading edge for an icon, `removable` on the trailing edge for a remove
button.

<CodeBlock lang="tsx" code={`import { styled, Box } from 'usemotif';
import { chipRecipe } from '@usemotif/recipes';

const Chip = styled(Box, chipRecipe);

<Chip intent="primary">design</Chip>
<Chip withIcon removable>
  <TagIcon /> filter <RemoveButton />
</Chip>`} />

## Stat

Two recipes: `statRecipe` stacks a figure's label, value, and help text in a column, and
`statDeltaRecipe` colours the change figure by `trend` (`up` · `down` · `neutral`).

<CodeBlock lang="tsx" code={`import { styled, Box, Text } from 'usemotif';
import { statDeltaRecipe, statRecipe } from '@usemotif/recipes';

const Stat = styled(Box, statRecipe);
const Delta = styled(Text, statDeltaRecipe);

<Stat>
  <Text>Revenue</Text>
  <Text fontSize="$fontSizes.xl">$48,200</Text>
  <Delta trend="up">↑ 12%</Delta>
</Stat>`} />

## Extending a recipe

Recipes are plain objects - spread one and add to it when you need a project-specific tweak, without
forking:

<CodeBlock lang="tsx" code={`import { buttonRecipe } from '@usemotif/recipes';

const Button = styled(Pressable, {
...buttonRecipe,
base: { ...buttonRecipe.base, borderRadius: '$radii.full' }, // pill buttons
});`} />
