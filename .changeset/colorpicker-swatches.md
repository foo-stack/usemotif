`ColorPicker` takes `swatches`, preset colours shown as a keyboard-navigable radio group with the matching swatch checked. It also takes `eyeDropper`, which adds a button that picks a colour from the screen through the browser EyeDropper API, shown only where the browser supports it. On React Native the swatches render as pressable radios and there is no eyedropper. The kit ColorPicker themes both.
