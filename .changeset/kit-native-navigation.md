The kit's navigation and disclosure components render on React Native: Tabs, Accordion, Collapsible, Breadcrumb, Pagination, Stepper, Toolbar, NavigationMenu, TreeView and CommandPalette, plus Separator, Stat, EmptyState, Timeline and AvatarGroup. Links open with `Linking` on native, and Breadcrumb's `onNavigate` defaults to it there. Web output is unchanged.
